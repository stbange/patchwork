## Why

Quilters use triangles, strips, diamonds and other shapes to build blocks. Patchwork needs to let a quilter browse complete layouts, try them with her fabrics and cut the pieces she sees on the design wall.

## What Changes

- Add a browsable library of 36 base designs, split evenly between traditional and modern blocks, with eight quilt settings per design.
- Draw and edit individual pieces in straight-seam blocks. Preview a design at the current quilt size and apply it in one undoable step.
- Save shaped blocks and export quantities, seam allowance templates and a placement map. Continue to open existing square plans.

## Capabilities

### Modified Capabilities

- `quilt-planning` covers the pattern library, individual pieces, cutting instructions and saved designs.

## Impact

The C model, SDL views, project format and cutting sheet change on Windows, Linux and Emscripten. The existing GitHub Pages workflow publishes the tested web build.
