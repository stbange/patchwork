## Decisions

Define each base block as a set of convex pieces on a 24-unit square. Coordinates are exact integers. The same geometry drives the gallery, design wall, pointer selection and cutting sheet. The browser and desktop share the editor.

A quilt setting decides where to place the selected block and how to turn it. The eight settings are Full repeat, Alternating, Offset, Rows, Columns, Diagonal, Border and Medallion. Picking an arrangement updates the preview. Applying it retains the current row count, column count and finished block size. Undo restores the previous plan. A quilter can click one piece, or use the arrows to move to a block and brackets to select a piece.

Store the family, setting, rotation and piece fabrics in version 2. Save original square plans in version 1 and continue to load existing projects on the same browser storage key and desktop path. Adding space gives the quilter plain fabric A squares and leaves the geometry of existing blocks in place.

Draw the finished edges on the design wall. In the text export, give the count by fabric for each cut template, the bounding width and height and the vertex coordinates of shaped templates. Compute the cut edge by moving each straight finished edge out 1/4 inch. The placement map identifies the fabric, template and turn of each block and gives the ordered sewing-line positions for its pieces.

For a 4-inch Pinwheel block, the four half-square units are 2 inches wide after sewing. Each unit contains two triangles. Changing the fabric of a triangle changes one triangle's count. The cutting reference covers the top laid out on the design wall.
