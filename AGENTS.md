# Patchwork

Use the [Ponytail skill](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md) when changing code. Start with the existing quilt model and SDL APIs. Keep the simple path readable and preserve validation, failure handling and tests.

Record behavior changes and sewing examples in OpenSpec. The build workflow documents the unit-only coverage gate and the desktop and browser journeys.
